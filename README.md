# دفترچه کارت ویزیت (Business Card Catalog)

اپ شخصی اسکن و مدیریت کارت ویزیت — React + Vite در فرانت‌اند، و یک تابع سرورلس کوچک که فراخوانی هوش مصنوعی (OCR/استخراج اطلاعات کارت) رو انجام می‌ده.

## چرا یک بک‌اند کوچک لازمه؟

نسخه‌ای که داخل چت کار می‌کرد از زیرساخت خود Claude برای صدا زدن مدل استفاده می‌کرد و کلید API نیازی نبود. وقتی این اپ رو خودت دیپلوی می‌کنی، دیگه اون زیرساخت وجود نداره — پس باید یک کلید Anthropic API خودت رو بدی. کلید هرگز نباید توی کد فرانت‌اند (که مرورگر همه می‌بینه) قرار بگیره، برای همین یک تابع سرورلس در `api/analyze.js` این کار رو انجام می‌ده: مرورگر عکس رو به این تابع می‌فرسته، تابع با کلید مخفی روی سرور با Anthropic صحبت می‌کنه، و فقط نتیجه (اسم، شرکت، تلفن و...) رو برمی‌گردونه.

## ذخیره‌سازی داده‌ها

مخاطبین و تنظیمات تلگرام توی `localStorage` مرورگر خودت ذخیره می‌شن — یعنی فقط روی همون گوشی/مرورگری که ازش استفاده می‌کنی هستن، نه یک اکانت مرکزی. از منوی «⋮ بیشتر» بالای اپ می‌تونی همیشه یه نسخهٔ پشتیبان (vCard یا CSV) از همهٔ مخاطبین بگیری.

## دیپلوی روی Vercel (پیشنهادی، رایگان و بدون تنظیمات پیچیده)

1. یک اکانت رایگان در [vercel.com](https://vercel.com) بساز (می‌تونی مستقیم با گیت‌هاب وارد بشی).
2. این پوشه رو به یک ریپوی گیت‌هاب پوش کن (یا مستقیم از CLI دیپلوی کن — پایین توضیح داده شده).
3. توی Vercel روی «Add New Project» بزن و ریپو رو انتخاب کن. فریم‌ورک به‌صورت خودکار Vite تشخیص داده می‌شه.
4. قبل از دیپلوی نهایی، برو به Settings → Environment Variables و یک متغیر اضافه کن:
   - Name: `ANTHROPIC_API_KEY`
   - Value: کلید API خودت (از [console.anthropic.com](https://console.anthropic.com))
5. Deploy رو بزن. چند ثانیه بعد یک آدرس مثل `your-app.vercel.app` بهت می‌ده.

### یا از خط فرمان (بدون گیت‌هاب):

```bash
npm install -g vercel
cd business-card-app
vercel
# سوالات رو جواب بده (اولین بار پروژه رو می‌سازه)
vercel env add ANTHROPIC_API_KEY
vercel --prod
```

## اجرای محلی برای تست

```bash
npm install -g vercel   # یک‌بار، اگه نداری
npm install
vercel dev              # هم فرانت‌اند و هم api/analyze.js رو با هم اجرا می‌کنه
```

اگه نمی‌خوای از Vercel CLI استفاده کنی و فقط UI رو بدون قابلیت اسکن هوش مصنوعی تست کنی:

```bash
npm install
npm run dev
```

## بعد از دیپلوی: نصب روی آیفون

آدرس دیپلوی‌شده رو توی سافاری باز کن، دکمهٔ Share رو بزن و «Add to Home Screen» رو انتخاب کن. آیکون اپ روی صفحهٔ اصلی گوشی می‌شینه و مثل یک اپ مستقل (بدون نوار آدرس مرورگر) باز می‌شه.

## ساختار پروژه

```
business-card-app/
├── api/
│   └── analyze.js      ← تابع سرورلس: پروکسی امن به Anthropic API
├── src/
│   ├── App.jsx          ← کل رابط کاربری اپ
│   ├── main.jsx         ← نقطهٔ ورود React
│   └── storage.js       ← ذخیره‌سازی محلی (localStorage)
├── index.html
├── package.json
├── vite.config.js
└── .env.example
```

## اگه به‌جای Vercel می‌خوای جای دیگه دیپلوی کنی

منطق اصلی توی `api/analyze.js` مستقل از Vercel نوشته شده (فقط یک تابع async که request/response می‌گیره)، پس برای Netlify Functions یا Cloudflare Workers یا یک سرور Node/Express معمولی فقط لازمه امضای تابع (handler signature) رو با اون پلتفرم تطبیق بدی؛ خود منطق فراخوانی Anthropic و پارس کردن JSON همونه.
